Kebijakan Hak Akses Sistem (Role-Based Access Control):
  • Role Admin (BR-09): Memiliki hak akses penuh untuk melakukan operasi CRUD pada seluruh data UMKM, produk, master kategori, dan wilayah.
  • Role Pelaku UMKM (BR-10): Hanya memiliki hak akses untuk mengelola profil dan produk pada unit UMKM miliknya sendiri.
  • Masyarakat Umum (BR-11): Pengguna publik hanya memiliki hak akses baca (Read-only) untuk eksplorasi peta, pencarian, dan melihat rincian produk.
  • Enkripsi Password (BR-15): Password disimpan dalam bentuk hash (bcrypt) dan tidak disimpan dalam plain text pada database produksi.
